The short version: the calculators run entirely in your browser, what you type stays on your device, and this page lists exactly which third-party scripts, if any, the site loads.

What the calculators store

Each calculator remembers the values you entered so the form is filled in when you return. This uses your browser's local storage, which lives only on your device. It is not transmitted to us or anyone else, and you can clear it with the Reset button on any calculator or by clearing site data in your browser.

Hosting

The site is static files served by GitHub Pages. GitHub may record standard server logs (IP address, requested page, browser type) as described in GitHub's privacy statement. We don't have access to per-visitor data from these logs.

Email

If you email us, we keep the message for as long as it's needed to reply and to act on it. We don't add addresses to any list.

Children

The site is not directed at children under 13 and does not knowingly collect information from them.

Changes

If the site starts or stops using analytics or advertising, this page is updated the same day the change goes live. The date at the top of the page reflects the last revision.
